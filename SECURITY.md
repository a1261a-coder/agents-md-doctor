# Security Policy

`agents-md-doctor` is a local CLI and should not send instruction files,
credentials, or repository content to external services.

## Supported Versions

The current `main` branch is supported.

## Reporting a Vulnerability

Please open a private security advisory on GitHub if the issue could expose
secrets, execute untrusted code, or create unsafe automation behavior.

For ordinary false positives or false negatives, open a public issue with a
minimal reproduction.
